# OAuth2 Hotmail Tool with Auto-Update

Tool hỗ trợ lấy OAuth2 Token và quản lý Outlook Hotmail tự động.

## Tính năng Tự động Cập nhật (Auto-Update)
- Tự động kiểm tra bản cập nhật mới nhất từ GitHub mỗi khi khởi động tool.
- Nếu có thay đổi trên GitHub, tool tự động tải về, tạo bản sao lưu (.bak) và cập nhật đè file hiện tại.
- Có nút **🔄 CẬP NHẬT** trên giao diện để cập nhật thủ công khi đang mở tool.
